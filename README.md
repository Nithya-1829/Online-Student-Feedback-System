# Online Student Feedback System

## Project Overview
The Online Student Feedback System allows students to register, log in, and submit feedback about their courses. Faculty can view the submitted feedback through a dashboard.

## Features
- Student registration and login
- View available courses
- Submit course ratings and comments
- Faculty feedback dashboard
- Store data in a MySQL database

## Technologies Used
- Frontend: React.js
- Backend: Node.js and Express.js
- Database: MySQL
- Version Control: Git and GitHub

## Project Structure
- `frontend/` – React user interface
- `backend/` – Express server and database connection

## How to Run
1. Install Node.js and MySQL.
2. Create the `student_feedback_db` database and required tables.
3. Configure the database credentials in `backend/.env`.
4. Open a terminal in the backend folder and run `npm install`, followed by `node server.js`.
5. Open another terminal in the frontend folder and run `npm install`, followed by `npm run dev`.
6. Open the local URL displayed by Vite in your browser.
